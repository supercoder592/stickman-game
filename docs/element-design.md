# 《元素極限：火柴人大亂鬥》全元素招式設計與特效指南

> 這份文件是遊戲的設計規格書。下方每一節都對應到 `scripts/skills/` 底下的一支實作腳本，
> 「實作位置」欄位標明程式碼在哪裡。

---

## 美術方向：鬼滅之刃 × 寶可夢

全部招式共用同一套視覺語言，實作在 `scripts/fx.gd`：

| 元件 | 函式 / 類別 | 用途 |
| --- | --- | --- |
| **毛筆新月斬** | `Fx.brush_slash()` | 《鬼滅之刃》呼吸法的核心識別。濃墨描邊 → 主體 → 內側亮芯 → 筆鋒飛白，四層疊出毛筆質感。風、火、金三系的斬擊都由它畫出。 |
| 新月多邊形 | `Fx.crescent()` | 沿圓弧生成兩端收尖、中段最厚的刃形，是 `brush_slash` 的幾何基礎。 |
| **漫畫集中線** | `Fx.SpeedLines` | 命中瞬間由中心炸開的放射線條，強化打擊感。所有元素命中時都會觸發。 |
| **浮世繪浪頭** | `Fx.Curl` | 阿基米德螺線捲曲的浪花，水系沿龍身不斷捲起；毒系爆炸也借用來做毒氣渦流。 |
| 帶狀膨脹 | `Fx.ribbon()` | 把中心線加上粗細變化後撐成封閉多邊形（水龍軀幹、光束外框、螺旋）。 |

另外在 `arena.gd::_build_environment()` 建立了 **2D 畫布泛光（glow）**：
`Environment.BG_CANVAS` + `background_canvas_max_layer = 0`，讓所有 ADD 混色的
特效自動溢光，而 HUD（layer 3）與商店（layer 5）不受影響。這需要 Forward+ 渲染器，
所以 `project.godot` 的 `rendering_method` 是 `forward_plus`。

寶可夢的部分主要體現在「招式的能量演出」：御劍術的地面六芒星法陣、
龍之怒的向心吸能與雙股螺旋光束、冰刺的地面霜華擴散。

## 四大基礎元素（玩家開局四選一，免費）

### 1. ⚡ 雷電 (Electric) — 【極速與麻痺】
- **寶可夢靈感**：皮卡丘（電光一閃、瘋狂伏特）
- **招式名稱**：【電光·極速伏特】
- **實作位置**：`scripts/skills/skill_electric.gd`
- **招式機制**：按下技能鍵後，火柴人化為一道電光向前方進行「Z」字型三次高速折返衝刺，
  最後爆發打擊。被命中的敵人會進入 0.5 秒的「麻痺硬直」。
- **Godot 4 純 GDScript 特效做法**：
  - 閃電線條：`_draw()` 搭配 `draw_polyline()`，以 `randf_range(-10, 10)`
    在起點與終點之間生成折點，畫出鋸齒狀的亮藍／金色閃電（`Fx.jagged()` +
    內部類別 `Bolt`，每 0.04 秒重抽一次形狀產生電流跳動感）。
  - 粒子殘影：衝刺時開啟 `CPUParticles2D`，`color = Color(1, 0.9, 0.2)`，
    `initial_velocity` 設為 0，讓粒子停留在軌跡上慢慢淡出（Blend Mode = ADD）。
    另外每 0.022 秒以 `StickFigure.Afterimage` 留下一份骨架殘影。

### 2. 🔥 熾焰 (Fire) — 【近戰爆發與持續灼燒】
- **寶可夢靈感**：小火龍（閃焰衝鋒、蓄能焰襲）
- **招式名稱**：【熾焰·烈焰勾拳】
- **實作位置**：`scripts/skills/skill_fire.gd`
- **招式機制**：帶有霸體的上勾拳，將前方敵人擊飛至空中並附加「灼燒」狀態（每秒扣血）。
- **Godot 4 純 GDScript 特效做法**：
  - 火焰粒子：`CPUParticles2D`，`direction = Vector2(0, -1)`（向上噴發），
    `color_ramp` 從亮黃 → 紅 → 透明。
  - 熱浪波動：動態生成漸變放大的圓（`Fx.Shockwave` 以 `draw_arc()` 實作），
    opacity 快速降低，模擬爆炸空氣衝擊波。

### 3. 💧 水流 (Water) — 【柔性推擠與遠程壓制】
- **寶可夢靈感**：傑尼龜（水砲、攀瀑）
- **招式名稱**：【水龍·咆哮】
- **實作位置**：`scripts/skills/skill_water.gd`
- **招式機制**：向前方召喚一條巨大的藍色水龍向前咆哮推動，強行將前方所有敵人推至
  螢幕邊緣並打斷敵方招式。
- **Godot 4 純 GDScript 特效做法**：
  - 動態水龍頭部：`draw_colored_polygon()` 繪製幾何頭部；軀幹由多條正弦波
    （`sin(time)`）構成的中心線，經 `Fx.ribbon()` 膨脹成滾動的水流。
  - 水花飛濺：龍頭掛載 `CPUParticles2D`，`emission_shape` 設為球形，
    噴射水藍色（`Color(0.2, 0.6, 1.0, 0.8)`）小圓滴粒子。

### 4. 🍃 疾風 (Wind) — 【高空位移與多段割裂】
- **寶可夢靈感**：飛天螳螂（起風、空氣斬）
- **招式名稱**：【風之呼吸·一型·塵旋風】
- **實作位置**：`scripts/skills/skill_wind.gd`
- **招式機制**：向前揮出一道高速旋轉的風刃切過地面，將沿途敵人微微牽引並造成多段微小切削傷害。
- **Godot 4 純 GDScript 特效做法**：
  - 風刃弧線：`draw_arc()` 畫出半透明淺綠色（`Color(0.5, 1.0, 0.5, 0.6)`）的弧形光刃，
    並讓它隨時間旋轉 `spin += delta * 20`。
  - 氣流殘影：沿風刃軌跡拋射極細長的綠色線段（`draw_line()` + `Fx.tex_shard()` 粒子），
    模擬空氣被割裂的質感。

## 五大技能樹元素（用遊戲幣 / 魔元解鎖）

### 5. 🧊 冰霜 (Ice) — 售價 750 金幣
- **寶可夢靈感**：乘龍（冰凍光束、絕對零度）
- **招式名稱**：【極寒·地表冰刺】
- **實作位置**：`scripts/skills/skill_ice.gd`
- **招式機制**：手掌擊地，前方地面順序刺出 5 道巨大冰柱，被刺中的敵人會被凍結 1.5 秒無法移動。
- **Godot 4 純 GDScript 特效做法**：
  - 冰晶生成：`draw_colored_polygon()` 動態生成冰晶的尖銳多邊形頂點
    （藍白色 `Color(0.8, 0.95, 1.0)`）。以 `create_tween()` 讓冰柱的 `scale.y`
    在 0.1 秒內從 0 快速拉高，呈現突刺感。
  - 冰屑碎裂：冰柱消失時在頂點釋放白色方形小粒子（`Fx.tex_square()`），帶重力向下掉落。

### 6. ☠️ 劇毒 (Poison) — 售價 1000 金幣
- **寶可夢靈感**：耿鬼（毒液衝擊、污泥波）
- **招式名稱**：【魔元·毒沼引爆】
- **實作位置**：`scripts/skills/skill_poison.gd`
- **招式機制**：在腳下創造一片紫色毒沼，踏入的敵人會被疊加毒素；再次按技能鍵可引爆毒素，
  造成「每層 2.5% 最大血量」的傷害。
- **Godot 4 純 GDScript 特效做法**：
  - 毒沼氣泡：地面繪製半透明紫色橢圓（`Fx.ellipse()`，Godot 無 `draw_ellipse()`，
    改以多邊形近似），區域內隨機生成向上飄浮、縮放變大的紫色圓形氣泡（`draw_circle()`），
    氣泡破裂時播放微小型粒子。
  - 毒氣瀰漫：`CPUParticles2D`，`gravity = Vector2(0, -20)`，顏色為深紫混薄荷綠。

### 7. 🌋 熔岩 (Lava) — 售價 1200 金幣
- **寶可夢靈感**：固拉多（斷崖之劍、噴火）
- **招式名稱**：【熔岩·地裂噴發】
- **實作位置**：`scripts/skills/skill_lava.gd`
- **招式機制**：向前方地表撕開一道裂縫，噴發出熾熱岩漿，地面留下一條持續 3 秒的岩漿帶，
  踏上的敵人會被持續灼燒與減速。
- **Godot 4 純 GDScript 特效做法**：
  - 裂縫與岩漿：繪製鋸齒狀黑色地表裂痕（`Fx.jagged()`），裂痕內部填充亮橙色與
    暗紅色相間、隨時間流動的波浪線條。
  - 岩漿濺射：`CPUParticles2D` 的 `initial_velocity` 設高（向上拋物線），
    粒子大小有大有小（`scale_amount_min/max`），模擬帶質感的熔岩塊噴發。

### 8. 🧲 鋼鐵／金屬 (Metal) — 售價 1500 金幣
- **寶可夢靈感**：巨鉗螳螂（飛葉快刀、鋼鐵頭殼）
- **招式名稱**：【金·御劍術】
- **實作位置**：`scripts/skills/skill_metal.gd`
- **招式機制**：召喚 6 把金屬金劍環繞自身旋轉，再按下技能鍵後自動鎖定全屏敵人穿透飛去。
- **Godot 4 純 GDScript 特效做法**：
  - 飛劍繪製：完全用 `draw_colored_polygon()` 畫出幾何劍身（銀白刃身 + 金黃護手劍柄）。
  - 飛劍軌跡：飛劍移動時以程式建立 `Line2D`（`Line2D.new()`）把歷史位置連成線，
    配合 `gradient` 與 `width_curve` 做出尾跡淡出，創造刺穿質感。

### 9. 🐉 龍之力 (Dragon) — 售價 3000 金幣（高階高代價）
- **寶可夢靈感**：烈空坐（龍之波動、流星群）
- **招式名稱**：【龍之怒·極限咆哮】
- **實作位置**：`scripts/skills/skill_dragon.gd`
- **招式機制**：需要 1 秒蓄力（期間全霸體），隨後向前方發射貫穿全螢幕的巨大龍形能量光束，
  造成毀滅性多段傷害。
- **Godot 4 純 GDScript 特效做法**：
  - 光束與震屏：繪製巨大矩形光柱，中央為純白、外圍加多層半透明藍紫色光暈。
    釋放時透過程式改變 `Camera2D.offset = Vector2(randf_range(-5,5), randf_range(-5,5))`
    實現震屏（統一由 `Arena.shake()` 管理）。
  - 能量聚集粒子：蓄力時 `CPUParticles2D` 的粒子方向設為向心收縮
    （`emission_sphere_radius` 大、`radial_accel` 為負值），將全屏粒子吸入火柴人體內。

## 實作上的補充決定

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 四大基礎元素補買價 | 300 金幣（`GameState.BASE_REBUY_COST`） | 原規格只寫「開局四選一免費」，未定義其餘三種如何取得 |
| 冰刺數量 | 固定 5 道 | 規格為 3~5，取上限手感較好，高度／寬度改為隨機 |
| 毒素引爆傷害 | 每層 2.5% 最大血量，上限 20 層 | 規格只寫「% 最大血量」，未給數值 |
| 御劍術第二段 | 手動再按一次；12 秒未發射則自動射出 | 避免飛劍無限期掛在場上 |
| 命中判定 | 不使用 `Area2D`，改用 `Rect2` / 圓形距離查詢 | 全程式建構，省去碰撞層設定，也讓招式範圍在程式碼裡一目瞭然 |
| 輸入 | 直接讀 `InputEventKey` / `Input.is_key_pressed()` | 不依賴 `project.godot` 的 InputMap，避免設定檔手寫出錯 |
| 字型 | 執行時載入系統中日韓字型（微軟正黑體等） | Godot 內建預設字型不含中文字符 |
