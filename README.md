# NEON CLASH 霓虹亂鬥

### ▶ [點這裡直接在瀏覽器玩](https://supercoder592.github.io/stickman-game/)

瀏覽器上的近戰街機格鬥。**十位霓虹鬥士**、三回合兩勝、連段／格擋／衝刺閃避／必殺技，
可以一個人打 AI、兩個人擠同一個鍵盤，或是輸入四位數房號跨裝置連線對戰。

* 純 JavaScript（ES modules）+ Canvas 2D，**沒有任何相依套件、沒有任何圖檔與音檔**
* 角色、場景、特效全部由程式畫出來；音效與背景音樂由 WebAudio 即時合成
* 手機可玩：內建虛擬搖桿與按鈕，觸控裝置自動開啟
* 連線用一支零相依的 Node 中繼伺服器（`server/relay.js`），同一支程式也負責把遊戲服務出去

> 這個 repo 的前身是 Godot 版的火柴人遊戲。這一版是**整個打掉重做**的網頁版：
> 新的美術方向（霓虹幾何）、新的十位角色、新的戰鬥系統與新的連線架構。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| `A` `D` | 移動 |
| `W` | 跳躍（疾翎可以在空中再按一次） |
| `S`（空中） | 快速落地 |
| `J` | 輕攻擊　連按三下＝三段連段，第三段把人打飛 |
| `K` | 重攻擊　慢，但出招後段有霸體，打中直接轟開 |
| `U` / `I` | 技能一 / 技能二（各自有冷卻） |
| `O` | 必殺技（氣條滿了才能放） |
| `L` / `Shift` | 衝刺閃避（有短暫無敵，空中可用一次） |
| 往後推 | **格擋**：朝遠離對手的方向推就會自動格擋，傷害降到 28% |
| `Esc` | 離開對戰 / 返回　`M` 靜音　`Enter` 確定 |

第二位玩家（雙人同機）：方向鍵移動、`Numpad 1` 輕、`2` 重、`4`/`5` 技能、`6` 必殺、`3` 閃避。

**規則**：三回合兩勝，每回合 60 秒，時間到血量高的人贏。
打人與被打都會累積氣條，滿了就能放必殺。

## 連線對戰

主畫面 →「連線對戰」→ 輸入四位數房號 →「連線」。
**兩邊輸入同一組房號就會配對**，先連進來的自動當主機。
配對後各自選角色、按 Enter 準備，主機會自動開打。

### 自己跑一台中繼伺服器

```bash
npm start                 # 預設 8787
PORT=3000 npm start       # 換個 port
```

這支伺服器做兩件事：把遊戲本身服務出去（`http://localhost:8787`），
以及在同房號的兩個人之間轉封包。零相依套件，只要有 Node 18+ 就能跑。

* **同一個區網**：兩台都開 `http://<主機的區網 IP>:8787`，位址欄留空即可。
* **跨網路**：把這支程式部署到一台雙方都連得到的機器
  （Render / Railway / Fly.io 之類的平台都可以，它們會自動附 TLS），
  然後在大廳的「中繼伺服器位址」填上 `wss://你的網域`。

> **從 GitHub Pages 玩連線必須用 `wss://`** —— Pages 是 HTTPS，
> 瀏覽器會拒絕從 HTTPS 頁面連到未加密的 `ws://`。

位址欄接受三種寫法：

| 輸入 | 實際連線 |
| --- | --- |
| （留空） | 跟遊戲同一台主機 |
| `example.com:8787` | `ws://example.com:8787` |
| `wss://relay.example.com` | 原樣使用（雲端平台用這種） |

### 同步模型

**主機權威**。主機跑完整模擬（雙方角色、招式、傷害、被動），
客戶端只做兩件事：把自己的輸入送上去，以及照著主機每秒 20 次的快照把畫面畫出來。
所有傷害判定只有主機算（`Battle.authoritative`），因此不會雙重扣血或分歧；
主機另外會把「誰放了什麼招」轉過去，客戶端在本地重播同一套特效，所以看得到彈道與光束。

快照裡的角色編號固定以主機為準（0 = 主機、1 = 客戶端），
客戶端照樣把自己畫在自己的那一側，**不會出現「血條顯示對手血量」這種鏡像錯誤**。

## 專案結構

```
index.html              外殼：畫布、CSS、掃描線濾鏡、模組載入
src/
  main.js               主迴圈（固定 60Hz）、畫面切換、輸入接線、連線訊息分派
  battle.js             一場對戰：回合、勝負、鏡頭、繪製順序
  fighter.js            戰鬥單位：狀態機、物理、傷害結算（dealDamage / receiveHit）
  combat.js             普攻招式表（起手／判定／收招、判定框、擊退）
  skills.js             招式元件庫：彈道／場域／地刺／光束／突進／連打／天降／引力…
  characters.js         十位角色的資料（數值、剪影零件、技能參數、被動）
  ai.js                 單機對手：輸出和玩家同格式的 InputFrame，不作弊
  rig.js                骨架與姿勢（走、跳、三段連段、重擊、施法、昇龍、受擊、倒地…）
  render.js             場景與角色繪製：霓虹夜城、地板網格、身體零件、武器
  gfx.js                繪圖原語：霓虹描邊、發光填色、新月斬、六角形、面板、文字
  fx.js                 特效系統：粒子、幾何特效、傷害數字、頓幀、震屏、白閃
  hud.js                對戰 HUD：血條、氣條、計時、回合點數、技能冷卻、連段數
  screens.js            主畫面、選角、連線大廳、結算
  input.js              鍵盤／觸控 → 統一的 InputFrame（位元遮罩帶按鍵邊緣）
  touch.js              手機虛擬搖桿與按鈕
  net.js                WebSocket 客戶端（房號、角色分配、封包收發）
  audio.js              WebAudio 合成音效與 16 步背景音樂
  util.js               數學、亂數、顏色小工具
server/relay.js         中繼伺服器 + 靜態檔案伺服器（手寫 WebSocket，零相依）
tools/build.js          打包成單一 HTML（dist/neon-clash.html）
docs/design.md          設計與架構說明
```

## 驗證

這一版用 Playwright（專案沒有把它列為相依，開發時才需要）實際在 Chromium 上跑過：

* **單機**：走過主畫面 → 說明 → 選角 → 對戰，十位角色逐一實例化並施放全部三招，0 錯誤
* **整場**：AI 對打到三回合兩勝，回合切換與結算畫面正常，0 錯誤
* **連線**：開兩個分頁、同房號配對 → 角色分配（host/guest）、雙方進入對戰、
  主機改血量客戶端同步（42/42）、客戶端的輸入讓主機端角色真的移動、
  客戶端看到的自己與主機差 1px，0 錯誤
* **打包檔**：`dist/neon-clash.html` 用 `file://` 開啟可正常啟動遊玩

## 加一位角色

在 `src/characters.js` 的 `ROSTER` 加一筆就會自動出現在選角、HUD 與所有畫面：

```js
{
  id: 'ivy', name: '常春', en: 'IVY', title: '荊棘園丁',
  color: '#8dff5a', accent: '#ffe27a',
  stats: { hp: 98, speed: 305, jump: 880, weight: 1, atk: 1, def: 1, dash: 1 },
  build: { scale: 1, limb: 1, head: 1, torso: 1 },
  look: { head: 'crown', back: 'tail', weapon: 'staff', shoulder: 'slim' },
  passive: { name: '再生', desc: '每秒回復少量血量。' },
  skills: [ { name: '藤鞭', cd: 3, kind: 'dashStrike', params: {...} }, ... ],
  ult: { name: '森羅', kind: 'vortex', params: {...} },
}
```

`kind` 對應 `src/skills.js` 裡的元件（共 20 種），`look` 的零件名對應 `src/render.js`
的頭部／背部／武器／肩甲畫法。需要全新的被動時，才需要動到 `fighter.js` 的
`dealDamage()` / `receiveHit()` / `counterPassives()`。
